---

## 🎯 Objetivo
Fazer um sistema de CRUD que reúna informações sobre clientes, seus respectivos animais e as raças a qual eles pertencem. Além disso, deve gerar relatórios em `.txt`, mostrando informações a partir de consultas no banco de dados.

---

## 🚀 Funcionalidades
* **✨ Gestão Completa:** Cadastro e edição de Clientes, Animais e Raças.
* **📊 Visualização Clara:** Visualização de todos os itens cadastrados no formato de tabelas.
* **🔍 Busca Inteligente:** Consulta de um determinado cadastro pela barra de pesquisas.
* **🔒 Segurança de Dados:** Exclusão lógica, permitindo alterar o estado de um item para inativo.
* **📄 Relatórios:** Geração de relatórios a respeito dos itens cadastrados no banco.
